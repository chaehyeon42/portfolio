Troubleshooting Experience

1. EKS - 온프레미스 VPN 연동 및 터널링 무중단 구축

인프라 네트워크 / VPN 프로토콜 규격 통일 및 통신 단절 장애 해결

Infra & Network
  • 문제 상황: EKS 파드 내부에서 외부 온프레미스 GPU 서버로의 통신이 거부(100% Packet Loss)되고, 방화벽 개방 후 통신이 성공해도 1시간 주기로 터널링이 강제 단절(Down)되는 치명적 장애 발생.
  • 해결 과정:

    ① 방화벽 및 라우팅 병목 해결: 온프레미스 우분투 방화벽(UFW)에서 AWS VPC 대역(10.0.0.0/16)을 전면 허용하고, AWS 정적 라우팅 설정에 로컬 사설 대역을 명시하여 길을 뚫어주었습니다.

    ② IKEv1 인증 규격 충돌(AUTH_FAILED) 해결: AWS 게이트웨이가 구형 IKEv1 규격으로 세팅된 것을 추적하여, ipsec.conf 설정의 암호화 알고리즘(DH Group 2 / modp1024)을 AWS 명세서와 100% 강제 동기화했습니다.

    ③ 1시간 주기 단절(Rekey Fail) 해결: 1시간마다 새로운 암호화 키로 교체(Rekey) 시 발생하는 단절을 막기 위해 rekey=yes, reauth=no 옵션으로 부드러운 갱신을 유도하고, 1분 주기의 Keep-Alive(Ping) 크론탭을 등록하여 유휴 상태(Idle) 차단을 방지했습니다.

  • 결과 및 습득 역량: 끊김 없는 안정적인 Site-to-Site VPN 무중단 통신 환경을 확립했습니다. 이 과정을 통해 블랙박스처럼 여겨지던 네트워크 계층의 암호화 프로토콜(IPSec Phase 1/2) 동작 방식을 저수준에서 분석하는 역량을 내재화했으며, 하이브리드 클라우드 인프라 설계 능력을 극대화했습니다.

2. CloudFront 및 ALB 환경의 HTTP 503 및 Mixed Content 에러 해결

쿠버네티스 헬스체크 및 HTTPS 프로록시 보안 정책 충돌 해결

Cloud & DevOps
  • 문제 상황: React 대시보드(HTTPS)에서 로그인 또는 카메라 영상을 호출할 때 HTTP 503 Service Unavailable 및 Mixed Content 에러가 발생하여 실시간 통신 및 영상 렌더링이 전면 마비됨.
  • 해결 과정:

    ① 503 에러 (ALB 헬스체크 실패): EKS 백엔드 파드는 정상이나 ALB 대상 그룹 상태가 Unhealthy로 떨어짐을 확인. K8s Manifest의 Health Check 경로를 /actuator/health로 교정하고, EKS 노드 보안 그룹에 ALB의 8080 포트 인바운드를 오픈하여 트래픽 전달을 복구했습니다.

    ② Mixed Content 및 CORS 에러: 클라우드의 HTTPS 웹사이트가 온프레미스의 HTTP(8010~8014 포트) 영상을 직접 호출하면서 발생하는 보안 차단을 막기 위해, AWS CloudFront를 도입하여 HTTPS로 중계했습니다.

    ③ ALB 대상 그룹 라우팅 분기: CloudFront의 /mjpeg/* 요청을 AWS ALB로 넘기고, ALB의 대상 그룹(Target Group)을 IP Type으로 설정하여 온프레미스 GPU 서버(공인 IP)의 각 포트별로 정밀하게 라우팅 분기 규칙을 생성했습니다.

  • 결과 및 습득 역량: 네트워크 라우팅 규칙과 CDN(CloudFront) 캐시/보안 정책을 결합하여 영상 송출 성공률 100%를 달성했습니다. 이를 통해 웹 브라우저의 최신 보안 정책(PNA, CORS)과 클라우드 로드밸런싱 계층 간의 상관관계를 통제하는 트러블슈팅 역량을 체득했습니다.
